가상 데스크톱 만들기와 이동

발표자료와 시연용 서비스 창을 서로 다른 데스크톱에 두면 화면을 정리하기 쉽습니다.

사용 순서

  1. Win + Tab으로 작업 보기를 엽니다.
  2. 새 데스크톱을 선택합니다. Win + Ctrl + D로 바로 추가할 수도 있습니다.
  3. 작업 보기에서 시연용 창을 원하는 데스크톱으로 옮깁니다.
  4. Win + Ctrl + 오른쪽 또는 왼쪽 화살표로 이동합니다.
  5. Win + Tab으로 전체 데스크톱과 열린 창을 확인합니다.
  6. 현재 데스크톱을 닫을 때는 Win + Ctrl + F4를 사용합니다.

가상 데스크톱은 열린 창을 정리하는 기능입니다. 계정이나 개인정보를 분리하는 보안 경계로 사용하지 않습니다.

확인할 결과

  • 발표자료와 시연 창을 구분해 두고 두 데스크톱 사이를 이동합니다.

막혔을 때

  • 가상 데스크톱 사용이 불편하면 Alt + Tab으로 창을 전환합니다.
